## Overview

Ignite Amps SHB-1 is a free bass guitar amplifier simulator delivering punchy, tight bass tones with a versatile EQ section and cabinet simulation suitable for metal and modern music.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Ignite Amps SHB-1** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Preamp Stage** | Gain-staged preamp with tight low-end response for metal bass |
| **EQ Section** | 4-band EQ with separate bass, low-mid, high-mid, and treble controls |
| **Cabinet Sim** | Built-in impulse response cabinet simulation with multiple speaker options |
| **Zero Latency** | Real-time processing with no added latency for live monitoring |
